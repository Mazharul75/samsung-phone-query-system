How it works

Four stages, matching the project's execution plan.

StepStageWhat happens
1Scraping & database Specifications for 15 Samsung phones are scraped from GSMArena and normalised into four MySQL tables.
2RAG chatbot Questions are classified, relevant documents retrieved with FAISS + BM25, and answered by a local open-source model grounded in SQL facts.
3Multi-agent reviews Three agents collaborate: one retrieves specifications, one ranks the phone against the catalogue, one writes the review.
4REST API Everything above is exposed over FastAPI. This page is a client of that API.
